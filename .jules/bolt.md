## 2024-07-07 - [React Performance] Text Input State Lifted Above Expensive Lists
**Learning:** In React applications like `vbt-sports-camp-web-app`, lifting the state of a frequent update (like a text input for an announcement) above a large and computationally expensive list (like `PhotoFeed`) can cause severe input lag. In this codebase, the text state lived in `App.jsx`, triggering re-renders of `PhotoFeed` on every keystroke, which contained an O(N log N) sorting operation on unmemoized items.
**Action:** When working with long lists where the parent may frequently re-render due to unrelated state changes (like text inputs), actively memoize sorting operations using `useMemo` and aggressively memoize individual list items (e.g. `AnnouncementCard`) using `React.memo` with proper prop comparison logic.
