# CEO Plan: VBT Sports Camp Service Expansion
Generated by /plan-design-review on 2026-07-09
Branch: main | Mode: SELECTIVE EXPANSION

## Vision

### 10x Check
Turn the VBT Portal & Service Mode into a white-label, multi-tenant camp SaaS platform. Any church or sports organization can register, configure locations, upload rosters, choose prebuilt rotation templates, and coordinate hundreds of volunteers on the field.

### Phased Roadmap
* **Phase 1 (Current Scope):** VBT Camp 2026 Single-Tenant Operational Enhancements. Build and optimize the core features (Agora Walkie-Talkie, Audio Chimes, Leaderboard, Point Deductions, and SVG Map) specifically for this camp's repository, using single-tenant Firestore collections.
* **Phase 2 (Deferred):** SaaS & Multi-Tenancy Architecture. Refactor databases to introduce tenant database separation (e.g., `/:tenantId/deductions` or tenant subdomains) and registration UI.

## User Role Definitions (Phase 1)
* **Site Admin (Heads):** Role value: `'admin'`. Access to full Portal configuration, Master Remote control, and Agora Walkie-Talkie voice channel.
* **Chaperone (Team Leader):** Role value: `'leader'`. Locked Service Mode displaying current/next station, with access to log behavior point deductions.
* **Station Referee (Game Leader):** Role value: `'referee'`. Locked Service Mode displaying rules flip-card and Win/Loss scoring calculator.
* **Public / Projector:** Read-only access to the Live Standings TV dashboard route.

## High-Contrast Outdoor Mode
For volunteer dashboard screens, the app automatically enforces a high-contrast light theme to combat direct outdoor sunlight and screen glare:
- Background: `#ffffff` (Pure White).
- Primary Text: `#0a1020` (Bold deep navy).
- Accents & Highlights: Solid primary red (`#ef4444`) and blue (`#3b82f6`) with thick black borders (`2px solid #000000`).
- Touch Targets: Buttons use a minimum touch target size of `64px` height with large font labels (`18px` bold).

## Technical Implementation Details (Phase 1)

### 1. Agora Walkie-Talkie VoIP Security & Scoping
* **Token Server Endpoint:** The frontend queries `${NOTIFY_SERVICE_URL}/agora-token` passing the Firebase User ID token in the `Authorization: Bearer <ID_TOKEN>` header for secure verification.
* **Channel Scoping:** Agora channels are namespaced by event code: `walkie_talkie_{eventCode}`.
* **Silent Token Refresh:** `WalkieTalkie.jsx` implements an automatic silent token refresh timer using `setTimeout` triggered 30 minutes prior to Agora token expiration.
* **Speaker Output:** Agora voice output is routed to the main speakerphone via `setEnableSpeakerphone(true)`.
* **Native Background Audio:** Native background capabilities for `audio` and `voice` are enabled in `Info.plist` (iOS) and `AndroidManifest.xml` (Android) to prevent call termination when backgrounded.

### 2. Audio Chimes & Sleep-Resiliency
* **Local Countdown Trigger:** Chimes are triggered locally by the client app when the countdown timer hits 0.
* **Client Time Sync:** Server time offset is calculated on startup by writing/reading a temporary document with `serverTimestamp()` to calculate client-to-server clock offset.
* **Wake-Lock Integration:** Configure the Capacitor application with a wake-lock plugin (`@capacitor-community/keep-awake`) to prevent screens from sleeping during active shifts on the field.
* **Autoplay Unlock:** Require that when users login and tap "Connect to Channel," the tap triggers a mandatory silent playback event (using a library like Howler.js inside `chimes.js`) to unlock the AudioContext for the session.

### 3. Database Scoping & Security Rules
* **Uniform Event Namespacing:** All operational collections are nested under `/vbt_events/{eventCode}` to maintain a consistent structure:
  - Timer: `/vbt_events/{eventCode}/timer`
  - Matches: `/vbt_events/{eventCode}/matches/{matchId}`
  - Deductions: `/vbt_events/{eventCode}/deductions/{deductionId}`
* **Firestore Security Rules:**
  ```javascript
  // Deductions Rules
  match /vbt_events/{eventCode}/deductions/{deductionId} {
    allow write: if get(/databases/$(database)/documents/vbt_servants/$(request.auth.uid)).data.role in ['admin', 'leader'];
  }
  // Matches Rules
  match /vbt_events/{eventCode}/matches/{matchId} {
    allow write: if get(/databases/$(database)/documents/vbt_servants/$(request.auth.uid)).data.role in ['admin', 'referee'];
  }
  ```

### 4. Game Leader Scoring Calculator
* **Firestore Write:** Referees write completed match outcomes directly to the `/vbt_events/{eventCode}/matches/{matchId}` collection.
* **Scoring Configuration:** `globalPoints` configuration rules (e.g. Points per Win/Loss/Tie) are read directly from the main event configuration document at `/vbt_events/{eventCode}`.
* **Score Mapping:** When referee clicks `[+ WIN RED 2]`, it sets:
  - `scores.red_2` = `globalPoints.win`
  - `scores.white_1` = `globalPoints.loss`
  - `winner` = `"red_2"`
  - `status` = `"completed"`

### 5. Standings Caching & Serverless Aggregation
* **Aggregate Cloud Function:** To prevent write races and frontend spoofing, a Firestore Cloud Function `aggregateTeamStandings` is triggered on any write to `/vbt_events/{eventCode}/matches` or `/vbt_events/{eventCode}/deductions`.
* **Team Totals Cache:** The function computes and writes aggregated standings data directly to `/vbt_events/{eventCode}/standings`.
* **Projector Route:** The `/standings-tv` route reads solely from `/vbt_events/{eventCode}/standings` to optimize read performance.

### 6. Interactive Camp SVG Map
* **SVG Map State:** Highlight location indicators on the SVG map based on the active block read from the live event timer document (`/vbt_events/{eventCode}/timer`) in Firestore.
* **SVG Element ID Mapping:** The active location name string is formatted (e.g., lower-case, hyphenated) to map directly to an HTML `id` attribute in the inline SVG map element.

## Accepted Scope (added to this plan)
- Agora VoIP integration inside WalkieTalkie.jsx with secure Bearer token authorization, speaker routing, and native background audio configuration.
- Audio chimes synchronization on rotation events via local timer counts synchronized with Firestore server time, secured with wake-lock plugins and background mode configs.
- Public projected standings dashboard route (`/standings-tv`) reading pre-aggregated standings documents calculated via Cloud Functions.
- Behavior point deduction logging to `/vbt_events/{eventCode}/deductions/{deductionId}`.
- Interactive SVG map layout with highlight indicators matching the active location read from `/vbt_events/{eventCode}/timer` mapped to SVG elements.
- Game Leader scoring calculator UI writing results to `/vbt_events/{eventCode}/matches/{matchId}` using dynamically loaded `globalPoints` rules.
